{{ SITE_NAME }} is designed to reduce risk when working with sensitive datasets. This page describes security practices and deployment expectations.

Access Controls

  • Authentication is required to upload, process, view, or download results.
  • Sessions are scoped to the creating user account.

Secure Downloads

  • When supported by the storage backend, downloads use time-limited signed URLs.
  • Signed URL lifetime is configurable by the deployment owner.

Data Minimization

  • Default retention is limited (original uploads: {{ ORIGINAL_RETENTION_DAYS }} days; results: {{ RESULT_RETENTION_DAYS }} days).
  • Users can delete sessions and associated files from the application.

Operational Security

  • Secrets are configured via environment variables.
  • Storage access is expected to follow least-privilege (separate keys for read/write where possible).
