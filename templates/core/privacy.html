This policy explains what {{ SITE_NAME }} stores and how we handle datasets and metadata. This is a product transparency statement and not legal advice.

Data We Store

  • Account data: email and profile fields you provide.
  • Session metadata: filename, row/column counts, selected parameters (k/l/t), and processing outcomes.
  • Uploaded datasets and processed outputs (depending on retention settings and your actions).

Storage & Access

  • Files are stored using the configured object storage backend (for example Cloudflare R2 when enabled).
  • Downloads may use time-limited signed URLs when supported by the storage backend.
  • Access to sessions is restricted to the authenticated user account that created them.

Retention

By default, retention is designed to minimize long-term storage of sensitive datasets:

  • Original uploads: {{ ORIGINAL_RETENTION_DAYS }} days.
  • Anonymized results: {{ RESULT_RETENTION_DAYS }} days.
  • Session records (metadata): up to {{ SESSION_RETENTION_DAYS }} days.

Deletion

You can delete sessions from the app. Deletion attempts to remove associated objects from storage as well as the database record.

Analytics

Analytics may be enabled to understand product usage and improve reliability. If enabled, analytics identifiers and settings are configured by the deployment owner.
